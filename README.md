This site is designed for personal use.

When building a basement food storage prep, I found that organizing and inventorying this information became difficult when looking for specific items. 

Utilizing Claude AI, GitHub and Firebase I was able to create a simple website that allows me to organize, inventory and search for specific items, as well as update quantity amounts as items get consumed. 

As a UX Designer of 16+ years with very little backend experience, this was a fun project for me to explore technologies I've never used before.
